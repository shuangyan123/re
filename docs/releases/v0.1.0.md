## Highlights

- Provider-independent evaluation through the `TutorUnderTest` boundary.
- A bilingual 48-case authored development cohort.
- Five tutoring capability categories: correctness, diagnosis, guidance,
  adaptation, and actionability.
- A deterministic evaluator boundary separated from semantic Judge criteria.
- A five-minute provider-free Quickstart.
- Corpus, replay, and canonical model-evidence paths for later reviewed runs.
- A static public website with a secret-free public-data firewall.
- Human Reference and calibration infrastructure, with validation still
  ongoing.
- Separate Apache-2.0 software, CC BY 4.0 benchmark-content, and TutorBench
  Brand Policy boundaries.

## Limitations

- The canonical full benchmark requires an explicitly configured Judge for
  semantic criteria; no-Judge runs fail closed with no score.
- There is no calibrated public leaderboard or verified public model result
  ingestion.
- The Community Review backend is not live and human calibration is ongoing.
- The authored benchmark is a synthetic development dataset.
- TutorBench measures observable behavior in benchmark cases; it is not a
  measure of long-term student learning, retention, transfer, or classroom
  outcomes.
