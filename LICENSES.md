# TutorBench license map

TutorBench is a multi-licensed project. The scopes below are separate; this
manifest is not an SPDX claim that every file is simultaneously licensed
under every listed license.

| Scope | Identifier | Governing text or policy |
| --- | --- | --- |
| Software implementation | `Apache-2.0` | [`LICENSE`](LICENSE) |
| Authored benchmark, dataset, and evaluation content | `CC-BY-4.0` | [`LICENSES/CC-BY-4.0.txt`](LICENSES/CC-BY-4.0.txt) and [`docs/licensing.md`](docs/licensing.md) |
| TutorBench name and brand assets | `TutorBench Brand Policy` | [`LICENSES/BRAND-POLICY.md`](LICENSES/BRAND-POLICY.md) |

`package.json` uses `SEE LICENSE IN LICENSES.md` because the npm package
contains software, authored benchmark content, and TutorBench brand assets
with different applicable boundaries. The package includes the referenced
license and policy files so consumers can inspect the scope map in the
installed artifact.

The scope rules, mixed-file guidance, attribution examples, and generated
artifact rules are maintained in [`docs/licensing.md`](docs/licensing.md).
